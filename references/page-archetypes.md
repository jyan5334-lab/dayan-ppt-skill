# P01-P18 页面原型库

## 使用方式

每页写一个 `archetype`（P 码）和 `silhouette`（轮廓）。先选页面要让观众完成的判断，再选 P 码；不得为了塞内容改变主结论。文字、数据、路径和图表保持可编辑。连续三页同一 `silhouette` 为阻断项。

| P 码 | 轮廓 | 解决的判断 | 结构与限制 |
|---|---|---|---|
| P01 | hero | 为什么值得听 | 全幅场景或大物件 + 两行内标题 + 一行副标题；封面不用目录或小卡片 |
| P02 | chapter | 接下来要回答什么 | 大图/纯色场 + 一个问题或结论；停顿页，信息不超过三项 |
| P03 | claim | 最重要结论是什么 | 大标题 + 一句解释 + 一处证据；留白大于文字区 |
| P04 | stat | 哪个数字改变判断 | 一个主数字 + 趋势/基准 + 口径脚注；不可并列摆四个无关系 KPI |
| P05 | trend | 变化是否真实、为何变化 | 单一趋势图 + 关键拐点注释 + 结论；时间连续，单位和来源可见 |
| P06 | compare | 两个对象差在哪 | 左右或前后对照；共同基准线、相同单位、最多三组比较 |
| P07 | evidence | 主张凭什么成立 | 证据分层：原始资料/案例/数据；主证据最大，辅助证据不超过两项 |
| P08 | path | 应按什么顺序推进 | 一条方向明确的路径，3-6 节点；先画线后放节点，线永不穿字 |
| P09 | timeline | 何时完成、关键节点在哪 | 水平或垂直时间轴；只放决定进度的节点，日期与责任人相邻 |
| P10 | map | 空间分布或区域机会在哪 | 地图/平面图 + 1-5 个明确标点；禁用无方向的装饰路线 |
| P11 | system | 系统如何运作、边界在哪 | 输入-处理-输出或分层架构；每层不超过四对象，箭头仅表示真实关系 |
| P12 | scenario | 方案进入真实场景后发生什么 | 55%-70% 场景大图 + 3 个动作标签 + 一条可验证价值 |
| P13 | case | 是否已有可复核验证 | 情境-动作-结果三段；使用真实案例、前后图、访谈或试点记录 |
| P14 | matrix | 应如何取舍或分层 | 二维坐标或优先级矩阵；坐标含义、气泡大小和结论必须明确 |
| P15 | quote | 谁的经验或承诺值得听 | 人物/原始资料为主，短引语 + 身份、日期、授权或出处 |
| P16 | exercise | 学员能否练习与反馈 | 任务-停顿-答案/标准；答案默认后出，讲解文字不替代练习 |
| P17 | decision | 现在需要谁决定什么 | 待决事项 + 选项 + 推荐 + 不决后果；只保留一个主决策 |
| P18 | close | 演示结束后下一步是什么 | 回扣开场主张 + 一个行动/请求 + 联系或下一步；不做单独“谢谢”页 |

## 场景映射

| 场景 | 首选组合 | 必须避开 |
|---|---|---|
| H01/H02 汇报 | P03, P04/P05, P06, P08/P09, P17, P18 | 结论滞后、无口径 KPI、无待决事项 |
| H03-H05 项目 | P03, P07, P08/P09, P11, P13, P17 | 把计划、执行、验收套成同一骨架 |
| H06 课件 | P03, P12, P16, P06, P18 | 只有概念和讲稿，没有练习反馈 |
| H07/H08 客户或品牌 | P01, P12, P07/P13, P06, P08, P18 | 以功能清单代替客户场景 |
| H09 路演 | P01, P12, P07, P06, P13, P08, P17/P18 | 团队页压过验证和请求 |
| H10 研究 | P03, P07, P05, P06, P14, P17 | 图表无样本、方法与局限 |
| H11/H12 传播 | P01, P02, P12, P13/P15, P18 | 煽情图片代替事实证据 |

## 轮廓编排规则

1. 一套 10-15 页至少使用 6 种轮廓；P01/P02/P18 不得连续出现。
2. 叙事段落默认采用 `claim -> evidence/data -> path/case -> decision`，而非连续信息列表。
3. 图表与流程页不使用浮动卡片承载正文；需要分组时使用网格、对齐线或色块区分。
4. 连接关系只存在于 P08/P09/P11/P14 等需要表达关系的页面；先绘制线和箭头，再放节点与文字，线层级永远在文字下方。
5. 一页出现两种以上重型结构（例如地图 + 矩阵 + 三张图表）时，拆为两页。
