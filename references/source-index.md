# 大琰PPT知识源索引

版本快照：2026-07-15。

## 结构化执行库

- `industry-scenario-matrix.md`：I01-I15行业与H01-H12横向应用矩阵。
- `scenario-blueprints.md`：12类场景必须回答的问题、必备页面、证据与页数。
- `industry-visual-cards.md`：15行业的视觉母题、对象、色彩、图表与禁止项。
- `page-archetypes.md`：P01-P18页面原型与场景映射。
- `chart-semantics.md`：C01-C12图表选择与数据口径规则。
- `motion-media-recipes.md`：M01-M08动效、媒体准入与静态降级。
- `template-style-study.md`：用户模板、品牌模板、截图和参考作品的风格提取与复用边界。
- `visual-asset-reverse-brief.md`：从页面反推图片/视频的图层、比例、文字安全区、Image 2调用和静态降级。
- `benchmark-suite.md`：六类代表性基准样例和规则升级后的回归要求。
- `parameter-schema.md`：production manifest字段、默认值与阻断项。
- `production-gates.md`：G0-G5生产门禁、评分、模板边界和硬失败项。
- `deck-types.md`：工作汇报、课件与路演的叙事分流。
- `narrative-patterns.md`：SCQA等可选叙事模式及其适用边界。
- `prompt-library.md`：总控、资料启动和典型场景口令。
- `validate-deck-plan.mjs`：制作前的结构化分镜验证器。
- `validate-visual-asset-plan.mjs`：图片/视频素材规格的生成前校验器。

## 原项目知识快照

- `project-production-parameters.md`：项目目录中的《PPT生产参数总表》快照。
- `project-industry-application-overview.md`：项目目录中的《PPT行业与横向应用分类总表》快照。
- `visual-and-motion-handbook.md`：项目目录中的《PPT视觉与动态演示复用手册》快照。

结构化执行库是日常生成的优先规则；原项目快照用于追溯背景、视觉方法和参数来源。两者冲突时，以用户当前明确要求、原始业务材料、最新结构化规则的顺序处理，并记录差异。

不把项目输出PPT作为固定模板打包。已验收PPT只抽象为案例规则，避免把单次色板、客户数据或版式误当成所有行业的默认答案。
