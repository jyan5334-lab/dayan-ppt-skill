# 可复用口令

## 总控口令

```text
使用 $dayan-ppt 制作一份【主题】PPT。

分类：I【行业代码/名称】 × H【横向应用代码/名称】；阶段为【规划/执行/复盘/验收/对外传播/比赛】。
受众与场景：【受众】在【场景】中观看，时长约【分钟】，希望他们最后【相信/学会/决定/行动】。
素材与边界：【可用资料、品牌资产、数据来源、不能虚构的内容】。

先输出创意简报和页面分镜，再开始制作。不要套模板，不要把内容做成卡片墙或泛化科技网格。
为本项目建立专属视觉母题、70/20/10 色板、图片对象和动效级别；每页一个主张和一个视觉焦点。
制作后逐页渲染检查，交付可编辑 PPT、动效说明、素材/许可记录和真实的剩余风险。
```

## 仅提供资料时的快速启动

```text
使用 $dayan-ppt。以下附件是本次 PPT 的全部文档、数据和图片，请先自动解析，不要直接排版。

请输出 production manifest：
1. 推断的 I 行业、H 使用场景、受众、项目阶段、时长和动效等级，并标注每项置信度；
2. 从原始资料中提取的核心主张、可复核数据、可用案例、可用图片与品牌资产；
3. 不可虚构边界、缺失证据、需要我确认的高风险项；
4. 创意简报与页面分镜。

若不影响事实与使用边界，请采用安全默认值继续；涉及外部发布、数据口径、目标受众、品牌或动画播放环境时，先问我 1-3 个关键问题。
```

## 缺图或缺动态素材

```text
使用 $dayan-ppt。附件是本次PPT的文档、数据和已有图片。

请先完成分镜，再从每页版式反推 visual-asset-plan：图片/视频槽位、占位比例、主体位置、文字安全区、背景/中景/前景图层、裁切方向、色彩光线、禁止项和静态降级。
缺少合适图片时，允许调用 Image 2 生成单个可组合素材，不要生成带中文文案、数据、Logo 或整页PPT的图片。AI图片只承担氛围和概念，不得作为真实地点、产品、人物、客户或成果的证据。
需要动态锚点时，先给出可静态阅读的首帧；只有我允许且播放环境可靠时，再生成6-10秒低速循环视频。先校验素材计划，再制作PPT。
```

## 全省 / 全国创新创业大赛路演

```text
使用 $dayan-ppt 制作一份【项目名称】创新创业大赛路演 PPT，面向【评委构成】，时长【X】分钟。

我要让评委清楚判断：我们解决的真实问题是什么、方案为什么有创新和可行性、已有何种验证、下一步需要什么资源或合作。
请采用“痛点 -> 方案 -> 差异化 -> 验证 -> 落地路径 -> 团队可信度 -> 请求”的叙事，不设置泛泛目录页。
视觉上用【产品/用户/实验/生产现场】作为母题，首页和章节页要有比赛级的场景张力；数据页必须有来源和口径，不能编造客户、收入、专利、奖项或市场规模。
动效采用 L2：2-4 个低速循环场景、主张先出证据后出、图表按讲述顺序出现。最后输出逐页动效表和评委可能追问的证据缺口。
```

## 课件 / 培训

```text
使用 $dayan-ppt 制作一份【课程主题】课件，学习者是【对象】，时长【X】分钟，学完后要能【具体能力】。

采用“问题 -> 概念拆解 -> 正反例 -> 操作步骤 -> 小练习 -> 复盘 -> 行动任务”结构。每个难点必须配一个案例、图示或演示；不要把讲稿完整放上页面。
视觉使用【真实对象/课程场景】作为母题，颜色承担分类；动效采用 L2，只用于逐步解释、步骤高亮和答案揭示，不使用抢注意力的转场。
交付可编辑 PPT、讲师备注、练习答案和逐页 QA 结果。
```

## 工作汇报 / 项目复盘

```text
使用 $dayan-ppt 制作一份【项目/部门】工作汇报 PPT，面向【管理层/协同方】，目标是在【X】分钟内促成【决策或资源动作】。

第一页就给结论；再按“结果与目标差异 -> 原因 -> 风险 -> 选项 -> 行动计划 -> 需要拍板事项”展开。所有数据写清统计口径、时间范围和来源，风险不能被淡化。
视觉保持克制、可信、易扫读：每页一个关键图表/对比/场景证据，避免假仪表盘和复杂动画。动效采用 L1，仅按讲述顺序揭示关键结论和数据。
交付可编辑 PPT、数据与素材来源、需决策事项清单和逐页 QA 结果。
```
