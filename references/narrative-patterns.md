# 可选叙事模式

## SCQA：用于问题到方案的开场

适用于 H03 项目立项/方案、H07 客户沟通、H09 路演，以及“问题明确、需要说服对方接受方案”的工作汇报。

| 段落 | 必须回答 | 页面表达 |
|---|---|---|
| S 情境 | 当前背景和共同目标是什么 | 事实背景、目标或趋势；避免空泛行业套话 |
| C 冲突 | 哪个差距、风险或痛点阻碍目标 | 真实问题、差距、案例或数据口径 |
| Q 问题 | 必须解决的核心问题是什么 | 一句可回答的问题，不是章节标题 |
| A 答案 | 方案、验证、路径与请求是什么 | 方案机制、证据、行动和需要的决策 |

每页仍要有独立的结论型标题和原始证据；SCQA 只决定叙事顺序，不替代行业场景蓝图。H05验收、H06课件、H10研究和纯数据复盘优先使用各自的必备结构，不强套SCQA。
