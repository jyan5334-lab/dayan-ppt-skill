# 交付类型分流

## 创新创业大赛 / 商业路演

**观众与任务**：评委、行业专家、投资方或合作方。让人相信项目值得进入下一轮、试点、投资或合作。

**推荐叙事**：开场张力 -> 真实痛点 -> 解决方案 -> 为什么现在 -> 差异化/创新 -> 验证证据 -> 商业或落地路径 -> 团队可信度 -> 请求与下一步。

**页面比例**：约 35% 问题与方案、25% 证据与场景、20% 路径与商业逻辑、10% 团队/资源、10% 请求与收束。不要用目录页浪费时间。

**视觉语言**：建立一个强母题，例如产品所在场景、用户旅程、实验/生产现场或品牌核心物件。封面和章节页让画面承担气质，数据页让证据承担说服。

**动效预算**：默认 L2。保留 2-4 个低速场景循环；每页先主张后证据；数据按讲述顺序揭示。开场不超过 15 秒建立张力，避免全页同时移动。

**必须避免**：虚构市场规模、夸张技术词、没有用户/验证的商业模型、团队介绍长过方案、把评委需要的判断藏在附录。

## 课件 / 培训 PPT

**观众与任务**：学习者。让人从“听过”走向“理解、能判断、能练习和能迁移”。

**推荐叙事**：为什么要学 -> 学完能做什么 -> 概念拆解 -> 示例/反例 -> 操作步骤 -> 小练习或提问 -> 复盘 -> 行动任务。

**页面比例**：约 40% 解释与可视化、20% 示例/演示、20% 练习与互动、10% 复盘、10% 资料与下一步。

**视觉语言**：高对比、可扫读、层级稳定。用真实案例、屏幕截图、示意图或过程照片帮助理解；分类色固定，但不用满页彩色卡片。

**动效预算**：默认 L2，但以教学顺序为准。概念按层拆开、步骤按操作顺序高亮、答案在思考停顿后揭示。一个页面连续动效通常不超过 2.5 秒。

**必须避免**：把讲稿完整贴到页面、先给答案再提问题、复杂转场干扰学习、动效抢走概念重点。

## 工作汇报 / 项目复盘 / 战略汇报

**观众与任务**：负责人、管理层、跨部门协同方。让人快速知道结论、状态、问题、选择和需要的决策。

**推荐叙事**：一句结论 -> 结果与目标差异 -> 原因 -> 风险 -> 选项/资源需求 -> 时间表 -> 需要拍板的事项。

**页面比例**：约 25% 结论、35% 数据与事实、20% 问题和风险、15% 行动与决策、5% 附录。

**视觉语言**：安静、可信、可扫描。白/浅灰为基底，主色服务结构，强调色只标记异常、风险或待决事项。优先一张关键图表、对比或场景证据，而非密集仪表盘。

**动效预算**：默认 L1。只对结论、关键数据和一个流程节点做顺序揭示；除非主题确实需要，不强塞循环场景。速度和信息准确性优先于炫技。

**必须避免**：结论埋在第 8 页、没有口径的数据、只汇报动作不汇报结果、回避风险、不给出需要管理层决策的明确句子。
