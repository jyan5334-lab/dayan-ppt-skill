# 行业与横向应用矩阵

先确定 `行业 I`，再确定 `横向应用 H`。同一行业内的不同 H 码必须按不同叙事和动效制作，不能共用一套模板。

## 横向应用 H01-H12

| 代码 | 使用方向 | 典型成果 |
|---|---|---|
| H01 | 战略与年度经营 | 战略规划、年度总结、年终述职、领导汇报 |
| H02 | 日常运营管理 | 周月季报、经营分析、专题复盘、风险通报 |
| H03 | 项目立项与方案 | 可研、申报、预算、投标、规划、项目介绍 |
| H04 | 项目执行与协同 | 进度、里程碑、跨部门协同、风险与资源协调 |
| H05 | 项目验收与成果 | 竣工/结题、验收答辩、成果汇报、评奖材料 |
| H06 | 教学与人才培养 | 课件、内训、知识分享、操作指引、招生宣讲 |
| H07 | 解决方案与客户沟通 | 售前方案、客户提案、诊断报告、商务沟通 |
| H08 | 产品、品牌与市场 | 产品发布、活动策划、营销复盘、品牌故事、招商 |
| H09 | 比赛、路演与融资 | 创新创业大赛、项目路演、融资、评审答辩 |
| H10 | 研究、政策与白皮书 | 调研报告、行业洞察、政策解读、研究成果 |
| H11 | 会议、会展与外部传播 | 峰会主视觉、论坛演讲、展会介绍、对外宣传 |

## 分类卡与生成规则

生成前先输出以下卡片；用户未明确时，先提出最影响方向的 1-3 个问题：

```text
分类：I【行业】 × H【使用方向】
受众：谁观看，谁作决定
阶段：规划 / 执行 / 复盘 / 验收 / 对外传播 / 比赛
时长与观看方式：现场 / 线上 / 自读
核心动作：希望观众批准、学习、合作、购买、评审或理解什么
证据：可用数据、案例、图片、视频、品牌资产及不可虚构边界
默认动效：L0-L3
```

同一行业的典型区分：

- `I09 × H06` 教育课件：学习闭环，L2；`I09 × H01` 教育年终总结：经营结果与决策，L1；`I09 × H05` 教学成果验收：证据链与答辩，L1。
- `I01 × H01` 党政年终总结：政治/治理结果与下一步，L1；`I01 × H05` 项目验收：指标、过程、合规与成果，L1；`I01 × H11` 对外发布：城市/项目价值传播，L2。
- `I02/I08/I10 × H09` 比赛路演：问题、创新、验证、路径与请求，L2；不能退化成普通项目介绍。
