# C01-C12 图表语义库

## 使用方式

先写“观众需要比较什么、基准是什么、要据此做什么判断”，再选择 C 码。所有图表对象和数据表必须可编辑；来源、统计期、单位、口径和结论缺一不可。没有可靠数据时使用 P07 证据页或 P12 场景页，不用假图表填充。

| C 码 | 要回答的问题 | 推荐表达 | 必备信息 | 禁止项 |
|---|---|---|---|---|
| C01 | 总量是否达标 | 单值/KPI + 目标基准 | 指标定义、目标、周期、单位 | 四个孤立数字并列 |
| C02 | 随时间如何变化 | 折线/面积趋势 | 连续时间、单位、拐点原因 | 断裂时间轴、无零点说明 |
| C03 | 各对象相差多少 | 排序条形/点图 | 同一口径、排名、单位 | 3D 柱、超过 8 类目 |
| C04 | 结构由什么组成 | 堆叠条/100% 堆叠 | 总量、分类边界、百分比 | 超过 5 类的饼图 |
| C05 | 目标与实际差距 | 目标线 + 实际条/子弹图 | 目标来源、差值、周期 | 只给完成率不说明目标 |
| C06 | 前后发生了何种改变 | before/after 对比 | 可比基准、前后时间、变化原因 | 不同单位的强行对比 |
| C07 | 哪些因素贡献最大 | 瀑布/贡献条 | 起点、增减项、终点、符号规则 | 只给结果不解释驱动项 |
| C08 | 区域或点位在哪 | 地图/热区/标点 | 地理边界、图例、数据日期 | 无方向的装饰路线 |
| C09 | 流程在哪卡住 | 漏斗/阶段转化 | 阶段定义、样本量、转化窗口 | 无样本量的转化率 |
| C10 | 资源该投向哪里 | 四象限/优先级矩阵 | x/y 维度、阈值、排序依据 | 没有坐标含义的气泡图 |
| C11 | 方案关系如何构成 | 桑基/系统关系图 | 流量单位、边的含义、边界 | 复杂线网压过文字 |
| C12 | 证据等级如何支持结论 | 证据阶梯/研究路径 | 证据类型、样本、局限、来源 | 以单一个案推出普遍结论 |

## 可读性和着色

1. 每页只让一个 C 码承担主结论；次级数据放备注或附录。
2. 使用基底色表示常规值，强调色仅标记主对象、异常、目标线或终点。颜色含义全套一致。
3. 默认不使用 3D、彩虹色、阴影柱、双轴、无标签的图例或数据透视截图。
4. 图表标题写结论，例如“Q2 交付速度恢复至目标区间”，不是“交付速度趋势”。
5. 数据被过滤、估算、脱敏或预测时，在脚注标明方法与边界。
