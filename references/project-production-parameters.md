# AI PPT 生产参数总表

版本：1.0  
用途：当你把文档、数据和图片交给 Codex 时，用这张表补齐必要参数；未填写的低风险项由系统采用安全默认值，高风险项会被标记为待确认。

## 1. 输入分级

| 级别 | 你需要提供什么 | 缺失后的处理 |
|---|---|---|
| 必填 | 行业、使用场景、受众、最终目标、项目阶段、资料/数据来源 | 系统可推断，但高风险项会先问 1-3 个关键问题 |
| 建议 | 时长、品牌资产、参考作品、必须出现/禁止出现内容、播放环境 | 系统按行业与场景使用默认值，并在 manifest 中说明 |
| 自动 | 页数、页面比例、色板、字体层级、图片比例、默认动效 | 由行业视觉卡、场景蓝图和安全默认值生成 |

## 3. 只丢资料时，系统如何自动处理

系统先输出 `production manifest`，其中包含：

1. 推断的行业 I、场景 H、受众、阶段和动效等级，并标注置信度。
2. 从资料提取的核心主张、数据、案例、图片、品牌资产和敏感信息。
3. 资料缺口：哪些事实无来源、哪些数字无口径、哪些图片无法公开使用。
4. 安全默认值：默认中文 16:9、业务对象可编辑、用户素材优先、汇报用 L1、课件/路演用 L2。
5. 需要你确认的高风险项：受众与最终行动、外发数据口径、品牌与保密边界、动效播放环境。

## 4. 必须建立的四个参数库

1. **12 类场景蓝图**：决定“内容怎么讲”。
2. **15 行业视觉卡**：决定“画面长什么样”。
3. **页面与图表库**：决定“每一页怎么组织”。
4. **动效与素材库**：决定“如何动、用什么素材、失败如何降级”。

四项已写入 `dayan-ppt` 技能：页面原型 P01-P18、图表语义 C01-C12、动效配方 M01-M08 会与行业和场景共同决定成片。用户提供PPTX、品牌模板或作品截图时，大琰PPT会先生成项目级style profile，再按“严格延续 / 视觉借鉴 / 品牌延展”执行。不要一次制作180套模板，而是用“场景蓝图 × 行业视觉卡 × 页面原型 × 图表/动效配方”组合生成。

每次分镜还应留下一个 `deck-plan.json`，并在开始制作前做结构预检：每页是否有主张、证据、视觉焦点和静态降级；是否连续三页同轮廓；数据页是否保留来源、单位和口径。这样能在排版前拦住“线条错位、卡片墙、图表空泛、动效不可播”等问题。

## 5. 交付前必过的参数检查

- 所有关键事实有来源，所有待核验内容已标记。
- 行业、场景、受众和阶段没有互相冲突。
- 数据图表含时间、单位、口径和结论。
- 图片/AI 图/字体有来源或可用边界。
- 动效与播放环境匹配，并有静态降级方案。
- PPT 可编辑、逐页渲染无溢出、质量评分达到 85 分。
